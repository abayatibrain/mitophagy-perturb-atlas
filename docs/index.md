# mitophagy-perturb-atlas

*A queryable atlas of CRISPR perturbation signals over the PINK1/Parkin mitophagy pathway — finds which gene perturbations phenocopy PRKN loss, with the cellular contexts where the signal lives.*

This documentation site mirrors the [README on GitHub](https://github.com/arminbayati/mitophagy-perturb-atlas#readme),
with additional pages for the biology primer, the architecture walkthrough,
the auto-generated API reference, and the full ADR-style decision log.

Start with **Biology primer** if you are an ML reader; start with **Architecture**
if you are a biologist or hiring manager scanning for what the code does.
