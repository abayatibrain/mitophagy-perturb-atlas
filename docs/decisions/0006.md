# ADR-0006: Phenocopy FDR methodology
Date: 2026-05-19
Status: Proposed — awaiting Armin sign-off

## Context

The atlas's headline output is a ranked list of phenocopy
candidates for a query gene. Without a calibrated significance
threshold, the ranking is just a sorted list — there's no honest
way to say "PRKN's top-50 phenocopies are statistically
significant" vs "the top scores look high but could be noise."

ADR-0004 commits to cosine as the similarity metric. This ADR
commits to the procedure that turns a cosine score into a
calibrated FDR statement.

The brief (§5.4 item 6) is explicit: "Empirical null via random
gene pairings; report FDR. Don't use a fixed correlation
threshold without justification." This ADR ratifies that
guidance and specifies the implementation.

## Options considered

### Option A — Empirical null by random gene pairing, per-modality
For each modality (DepMap, Replogle-K562, Replogle-RPE1),
sample N random gene pairs, compute their cosine similarity,
and use that empirical distribution as the null. FDR is then
the fraction of null pairs with similarity ≥ the observed.
- Pros: makes no parametric assumption; respects the per-
  modality scale; tractable computationally.
- Cons: assumes the random pairing is a valid null (it is, for
  this question — we're asking "is PRKN-X more similar than two
  random genes?").

### Option B — Parametric null (Fisher z on Pearson)
For Pearson, transform to Fisher z and use the normal
approximation.
- Pros: closed-form; very fast.
- Cons: requires Pearson (we headline cosine); the normal
  approximation breaks down in the high-similarity tail where
  the interesting candidates live.

### Option C — Block-permutation null
Permute within Reactome pathway blocks to preserve pathway
structure under the null.
- Pros: more conservative for in-pathway pairs; reduces false
  positives driven by pathway-level co-expression.
- Cons: introduces a pathway-definition dependency into the
  null (so the null depends on ADR-0005's choice); harder to
  defend without making the README very long.

### Option D — No FDR; report raw similarity ranks only
Just show the top-N.
- Pros: simplest.
- Cons: the brief explicitly disallows this; reviewers will ask
  for FDR; the atlas's value proposition is "calibrated" not
  "ranked."

## Criteria for choosing
1. **Brief compliance.** §5.4 item 6 explicitly names "empirical
   null via random gene pairings."
2. **Calibration on synthetic data.** Whatever procedure is
   chosen must produce FDR estimates that match nominal levels
   when run on synthetic data where ground-truth is known.
3. **Per-modality independence.** ADR-0001's separate-spaces
   framing requires per-modality null computation; a single
   global null would violate that.

## Decision

**Option A: empirical null by random gene pairing, computed
independently per modality.** For each modality, sample
``n_null = 10_000`` random pairs; the FDR for a query-target
pair is the fraction of null pairs with similarity ≥ observed.

A pair is reported as "FDR-significant" when:
- Within-modality FDR < 0.05, AND
- The pair appears in the top-N (default 100) of the per-
  modality ranking.

Per ADR-0001, a pair that is FDR-significant in *both* DepMap
and at least one Replogle subset gets the "convergent across
modalities" badge in the dossier.

## Consequences
- Each phenocopy table carries an ``fdr_within_modality`` column.
- The empirical null is sampled once per release (ADR-0002 pin)
  and cached, with a deterministic seed.
- The synthetic-data calibration test belongs in v1.0.0's test
  suite and must pass before release.

## Open questions for Armin
1. Confirm Option A (empirical null, per-modality, n=10k).
2. Confirm the FDR cutoff (0.05) and the top-N cutoff (100).
3. Should the "convergent across modalities" badge require
   significance in DepMap AND both Replogle subsets, or DepMap
   AND any Replogle subset?
