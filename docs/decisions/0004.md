# ADR-0004: Similarity metric for perturbation profiles
Date: 2026-05-19
Status: Proposed — awaiting Armin sign-off

## Context

The atlas's central operation is: given a query gene (e.g., PRKN),
return the top-N most similar perturbations by their profile in each
modality (DepMap fitness profile across cell lines; Replogle K562 /
RPE1 transcriptional signatures). The choice of similarity metric
determines what "similar" means biologically and how the empirical
null (ADR-0006) is constructed.

This is a real biology decision: different metrics emphasise
different aspects of the perturbation profile.

## Options considered

### Option A — Cosine similarity
Angle between two profile vectors, ignoring magnitude.
- Pros: scale-invariant; well-behaved in high dimensions; standard
  default in scanpy/scikit-learn; preserves *sign* of effect (PRKN
  and USP30 should anti-correlate, and cosine captures that).
- Cons: ignores the magnitude of perturbation effect, so a strong
  partial-phenocopy looks similar to a weak full-phenocopy.

### Option B — Pearson correlation
Cosine after mean-centering. Standard in many perturbation atlases.
- Pros: removes per-perturbation mean offset (controls for global
  technical effects per gene); also sign-preserving.
- Cons: very correlated with cosine in practice; mean-centering can
  amplify low-signal residual noise on quiet genes.

### Option C — Mutual information (binned)
Information-theoretic similarity; captures non-linear relationships
that cosine/Pearson miss.
- Pros: catches non-linear gene-gene relationships (e.g., threshold
  effects, switches).
- Cons: requires binning and bias correction; sign-blind by
  default; very slow on genome-wide pairwise.

### Option D — Spearman rank correlation
Rank-based; robust to outliers.
- Pros: insensitive to one-cell-line outliers in DepMap fitness.
- Cons: throws away effect magnitude; sign-preserving but reduced
  resolution.

## Criteria for choosing
1. **Sign preservation.** USP30 (deubiquitinase, opposes Parkin)
   must anti-correlate with PRKN. Any sign-blind metric is wrong
   for this atlas.
2. **Computational cost.** Genome-wide pairwise on three modalities
   means ~3 × (20k × 20k) similarity matrices. The metric must be
   tractable.
3. **Empirical-null tractability.** The metric must allow a
   permutation-based null distribution (ADR-0006) at reasonable
   wall-clock cost.
4. **Interpretability for the dossier.** A reviewer should be able
   to look at a high-similarity pair and understand why.

## Decision

**Option A (cosine) for the headline similarity.** Per-modality.
Reported alongside Option B (Pearson) in a secondary column for
the same pair so a reviewer can spot pairs where the two metrics
disagree (a red flag). Spearman (Option D) is computed only on the
DepMap fitness modality, where one-line outliers are most likely;
it appears in the dossier's "robustness" section as a sanity
check, not as a headline.

Mutual information (Option C) is **deferred**. The published
mitophagy literature uses cosine/Pearson by default; introducing
MI would create a defendability burden out of proportion to its
incremental value for v1.0.0.

## Consequences
- The headline ranking uses cosine.
- Every dossier shows cosine + Pearson side by side; disagreement
  >0.1 in any pair gets a flag.
- Spearman is computed and stored but only shown in the robustness
  section.
- The empirical null (ADR-0006) is computed on cosine.

## Open questions for Armin
1. Confirm cosine as the headline metric.
2. Confirm Spearman robustness check is in scope for v1.0.0.
3. Confirm MI is acceptably deferred (and what would trigger
   adding it later).
